CAFE KIAAN - ODOO 17

1) Install Odoo 17 Community + PostgreSQL.
2) Run START_ODOO.bat.
3) Open http://localhost:8070.
4) Install/update "Café Kiaan Restaurant Customization" from Apps.
5) Run START_FRONTEND.bat.
6) Open http://localhost:3000.

Odoo is now the backend. There is no FastAPI/MongoDB dependency in the final project.
