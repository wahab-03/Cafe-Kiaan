# Café Kiaan Architecture

- Frontend: Next.js 14 + React 18
- Backend/API: Odoo 17 custom module `cafe_kiaan_restaurant`
- Database: PostgreSQL 17
- Restaurant Menu: `product.template`
- Website Restaurant Orders: `sale.order`
- Customers: `res.partner`
- Purchases: `purchase.order`
- POS: `pos.order`

There is no separate FastAPI/MongoDB service in the final project. The `backend/` directory contains documentation only.
