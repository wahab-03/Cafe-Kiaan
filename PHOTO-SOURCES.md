# Café Kiaan menu photo sources

The frontend still receives menu records from Odoo. The curated image map in `frontend/lib/menu-images.js` only changes presentation images by menu-item name; it does not change product IDs, prices, availability, featured flags, or order/cart logic.

## Final selected source

The final menu set uses Pexels CDN images because the selected photos are free-to-use Pexels photos and provide consistent food-photography quality. Pexels search results were compared with corresponding Unsplash and Pixabay results before selecting the final images.

## Cross-source checks

For each menu category/item, searches were checked across:
- Unsplash: https://unsplash.com/
- Pexels: https://www.pexels.com/
- Pixabay: https://pixabay.com/

Exact food-match, photographic quality, composition, aspect ratio, watermark/logo risk, and suitability for a restaurant menu were used as selection criteria. Pexels was the final choice for this revision.
